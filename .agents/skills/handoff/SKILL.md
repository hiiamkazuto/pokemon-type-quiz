argument-hint: "次のセッションでは何を行いますか？"

---

新しいエージェントが作業を継続できるよう、現在の会話を要約した引き継ぎドキュメントを作成してください。保存先はユーザーのOSの一時ディレクトリとします。

ドキュメントはそれ単体で完結して読めるように作成してください。過去の引き継ぎ内容で今も有効な事項がある場合は、すべて今回のドキュメント本文に直接書き直して取り込みます。

ドキュメント内に「推奨スキル」セクションを含め、次のエージェントが呼び出すべきスキルを明記してください。

仕様書、計画、ADR、Issue、コミット、差分など、他の正式な成果物に記録されている内容は、パスやURLで参照してください。

APIキー、パスワード、個人を特定できる情報などの機密情報はすべてマスクしてください。

ユーザーが引数を渡した場合は、それを次のセッションで注力すべき内容の説明として扱い、その内容に合わせてドキュメントを調整してください。

作成後、ドキュメントの絶対パスを応答の末尾に次の形式で伝えてください：

```
📄 引き継ぎドキュメント: `<絶対パス>`
```
