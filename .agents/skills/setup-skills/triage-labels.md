# トリアージラベル

各スキルは5つの標準的なトリアージ役割に基づいて動作します。このファイルは、それらの役割をこのリポジトリのIssueトラッカーで実際に使用するラベル文字列にマッピングします。

| 標準ラベル | このトラッカーにおけるラベル | 意味                                     |
| ------------------------------- | ---------------------------- | ---------------------------------------- |
| `needs-triage`                  | `needs-triage`               | メンテナーによるこのIssueの評価が必要    |
| `needs-info`                    | `needs-info`                 | 報告者からの追加情報を待っている状態     |
| `ready-for-agent`               | `ready-for-agent`            | 仕様が確定し、自動エージェントが着手可能 |
| `ready-for-human`               | `ready-for-human`            | 人間による実装が必要                     |
| `wontfix`                       | `wontfix`                    | 対応しない                               |

スキルが役割に言及した場合（例:「自動エージェント対応可能のトリアージラベルを適用する」）、この表の対応するラベル文字列を使用してください。

実際に使用している体系に合わせて右側の列を編集してください。
