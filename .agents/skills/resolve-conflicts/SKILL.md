---
name: resolve-conflicts
description: "進行中の git merge や git rebase の競合を解消する必要がある場合に使用します。"
---

1. **現在の状態を確認する** マージまたはリベースの現状を確認します。gitのコミット履歴と、競合しているファイルを確認してください。

2. **競合ごとの一次資料を確認する** なぜその変更が行われたのか、本来の意図は何だったのかを深く理解します。コミットメッセージを読み、PRを確認し、元のIssueやチケットを確認してください。

3. **各競合箇所を解消する** 可能な限り双方の意図を維持します。両立できない場合は、今回のマージの目的に合致する方を選択し、そのトレードオフを明記してください。新しい振る舞いを勝手に作り出しては**いけません**。必ず解消し、決して `--abort` で中断しないでください。

4. プロジェクトの**自動チェック**を特定して実行する — 通常は型チェック、次にテスト、最後にフォーマットの順です。マージによって破損した箇所があれば修正してください。

5. **マージまたはリベースを完了させる** すべてをステージングしてコミットします。リベースの場合は、すべてのコミットのリベースが完了するまで処理を継続してください。
