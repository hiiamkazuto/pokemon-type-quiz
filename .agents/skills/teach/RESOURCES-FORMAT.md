# RESOURCES.md の形式

`RESOURCES.md` は、このトピックに関して厳選された信頼できる情報源のリストです。解説のための知識は、モデルの推測ではなくここから引き出す必要があります。また、知恵はここに記載されたコミュニティから得られます。

## 構造

```md
# {トピック} リソース集

## 知識

- [書籍: 『ストレングストレーニングの科学と実践』 — ザツィオルスキー、クレーマー](https://example.com)
  プログラミングと適応に関する基礎的文献。用途: ピリオダイゼーション、回復、強度ゾーンに関するあらゆる事項。
- [記事: 「どのくらいトレーニングすべきか？」 — グレッグ・ナックルズ（Stronger By Science）](https://example.com)
  トレーニングボリュームの指標に関するエビデンスに基づくレビュー。用途: 筋群ごとの週間目標セット数。

## 知恵（コミュニティ）

- [r/weightroom](https://reddit.com/r/weightroom)
  質の高いSubreddit。俗説が厳しくモデレーションされている。用途: プログラムの講評、停滞期のトラブルシューティング。
- 地域: {ジム名} の火曜ストレングスクラス
  用途: リフティングフォームに関するリアルタイムのコーチングフィードバック。
```

## ルール

- **信頼性の高いものに限定する。** 一次資料、定評ある専門家、査読付き論文、厳格にモデレーションされたコミュニティを優先してください。教育を装った単なるマーケティング資料は除外します。
- **すべての項目に解説を添える。** URLだけの一覧は後から見返したときに役に立ちません。何を扱っているか、どのような場面で参照すべきかを1行添えてください。
- **知識と知恵で分類する。** [`SKILL.md`](./SKILL.md) の指導理念に沿って分類します。どちらか一方のみに掲載されるリソースがあっても問題ありません。
- **不足している領域を明示する。** ミッションに必要な領域で適切なリソースが見つからない場合は、`## 不足しているリソース` セクションを設け、何が足りないかを一覧化してください。今後の探索の指針となります。
- **徹底的に選別・整理する。** 不正確、浅薄、またはミッションから外れていると判明したリソースは放置せず削除してください。30個の平凡な情報源よりも、5個の研ぎ澄まされた情報源の方が価値があります。
- **コミュニティ参加の方針を記録する。** ユーザーがコミュニティへの参加を希望しない場合はその旨を記録し、今後のセッションで提案を繰り返さないようにしてください。
