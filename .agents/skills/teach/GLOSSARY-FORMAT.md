# GLOSSARY.md の形式

`GLOSSARY.md` は、このティーチングワークスペースにおける標準的な用語集です。すべての解説、演習、学習記録は、この用語体系に準拠する必要があります。用語集を構築すること自体が学習の一部であり、概念を厳密な定義へと凝縮することは、ユーザーがそれを理解した証拠となります。

## 構造

```md
# {トピック} 用語集

{この用語集がカバーするトピックに関する1〜2文の説明。}

## 用語

**筋肥大**:
繰り返しのトレーニングセッションを通じて、機械的張力と代謝ストレスによって引き起こされる筋肉の成長。
_推奨しない表現_: バルクアップ、体を大きくする

**漸進性過負荷（プログレッシブ・オーバーロード）**:
負荷、ボリューム、または強度を通じて、時間をかけて筋肉への要求を体系的に増大させること。
_推奨しない表現_: より強く追い込む、レベルアップ

**自覚的運動強度（RPE）**:
セットの負荷を1〜10で自己評価する指標（10は限界、8は余力が2レップある状態）。
_推奨しない表現_: 努力スコア、強度レーティング
```

## ルール

- **ユーザーが理解した用語のみを追加する。** 用語集は凝縮された知識の記録であり、ユーザーが学習のために読む辞書ではありません。概念に触れたばかりの段階では追加を見送り、正しく使えるようになったことを確認してから追加してください。
- **最善の用語を1つ定める。** 同一の概念に対して複数の単語が存在する場合、最も適切な用語を1つ選び、それ以外の表現を非推奨として列挙してください。これによって語彙が集約されます。
- **定義は簡潔に保つ。** 1〜2文に収めます。その用語の実行方法や効果ではなく、その用語が「何であるか」を定義してください。
- **用語集内の他の用語を用いて定義を記述する。** 定義文の中でも用語集の確立された用語を積極的に活用してください。これによって、後から複雑な概念を理解しやすくなります。
- **自然なまとまりがあればサブ見出しでグループ化する。** 分類が明確な場合はサブ見出し（例: `## 解剖学`、`## プログラミング`）でグループ化してください。語彙数が少ない段階ではフラットな一覧で十分です。
- **一般的な曖昧さは明確に規定する。** その分野で曖昧に使われている用語がある場合は、このワークスペースでの定義を明記してください（例: 「本ワークスペースにおいて『セット』は常にメインセットを指し、ウォームアップは別個に記録します」など）。
- **理解が深まるのに合わせて更新する。** 初週に記述した定義が6週目には不正確になることがあります。過去の不正確な記述を残さず、その場で直接最新の理解に更新してください。
